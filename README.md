# Agile Planner

Agile Planner — настольное приложение для личного управления задачами, разработанное на Python с использованием Tkinter.

## Возможности

- Добавление и удаление задач.
- Назначение приоритетов: низкий, средний, высокий.
- Изменение статусов: To Do, In Progress, Done.
- Просмотр списка задач.
- Расчёт процента выполненных задач.
- Автоматическое сохранение данных в JSON.

## Используемые технологии

- Python 3
- Tkinter — графический интерфейс.
- JSON — хранение задач.
- unittest — тестирование.

## Установка и запуск

1. Скачайте или клонируйте репозиторий.
2. Установите Python 3, если он ещё не установлен.
3. Убедитесь, что команда `python` доступна в командной строке Windows.
4. Запустите файл `run.vbs` для запуска без окна командной строки или `run.bat` для запуска через CMD.

Также приложение можно запустить командой:

```bash
python app.py
```

Дополнительные библиотеки устанавливать не требуется.

## Тестирование

Для запуска автоматических тестов выполните:

```bash
python -m unittest discover -s tests -v
```

## Хранение данных

Задачи сохраняются локально в файле `data/tasks.json`. При повторном запуске приложения данные загружаются автоматически.
