# Agile Planner

Персональный планировщик задач, предназначенный для организации личной работы с использованием Agile-подхода.

## Основные возможности

- Создание новых задач.
- Редактирование и удаление задач.
- Назначение приоритетов.
- Отслеживание статусов: To Do, In Progress, Done.
- Планирование задач по спринтам.
- Просмотр прогресса выполнения.

## Структура проекта

- `docs/` — документация проекта.
- `src/` — исходный код приложения.
- `tests/` — материалы тестирования.
