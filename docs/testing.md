# Тестирование Agile Planner

## 1. Цель тестирования

Цель тестирования — проверить корректность работы основных функций приложения Agile Planner, выявить возможные ошибки и убедиться, что приложение соответствует установленным требованиям.

## 2. Объект тестирования

Объектом тестирования является веб-приложение Agile Planner, разработанное с использованием HTML, CSS и JavaScript.

Проверяются следующие функции:
- создание задач;
- удаление задач;
- изменение статусов;
- фильтрация задач;
- отображение прогресса;
- сохранение данных в LocalStorage.

## 3. Виды тестирования

В рамках проекта используются следующие виды тестирования:

1. **Функциональное тестирование** — проверка выполнения основных функций приложения.
2. **Тестирование интерфейса** — проверка отображения элементов и доступности кнопок.
3. **Тестирование хранения данных** — проверка сохранения задач после обновления страницы.
4. **Регрессионное тестирование** — повторная проверка основных функций после внесения изменений.

## 4. Условия проведения тестирования

Тестирование проводится на персональном компьютере в современном веб-браузере.

Для запуска используется файл `src/index.html`.

## 5. Результаты тестирования

В ходе проверки успешно выполнены следующие действия:
- создание новых задач;
- удаление существующих задач;
- изменение статусов задач;
- фильтрация по статусам;
- отображение количества выполненных задач;
- сохранение данных после обновления страницы.

По результатам проведённых проверок основные функции приложения работают корректно.

## 6. Вывод

Проведённое тестирование подтвердило работоспособность основных функций Agile Planner. Критических ошибок в проверенных сценариях не обнаружено.
