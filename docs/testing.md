# Тестирование Agile Planner

## 1. Цель тестирования

Цель тестирования — проверить корректность работы основных функций приложения Agile Planner, разработанного на Python.

## 2. Средства тестирования

Для автоматического тестирования используется стандартная библиотека Python `unittest`.

Тесты находятся в файле `tests/test_task_manager.py`.

## 3. Проверяемые функции

| № | Функция | Ожидаемый результат |
|---|---|---|
| 1 | Добавление задачи | Задача появляется в списке |
| 2 | Удаление задачи | Выбранная задача удаляется |
| 3 | Изменение статуса | Статус задачи обновляется |
| 4 | Расчёт прогресса | Процент выполнения рассчитывается правильно |
| 5 | Сохранение данных | Задачи записываются в JSON |
| 6 | Загрузка данных | Сохранённые задачи восстанавливаются |

## 4. Результаты автоматического тестирования

Для запуска тестов используется команда:

```bash
python -m unittest discover -s tests -v
```

В ходе проверки модуля `task_manager.py` успешно пройдены четыре автоматических теста:

- `test_add_task` — успешно;
- `test_delete_task` — успешно;
- `test_progress` — успешно;
- `test_update_status` — успешно.

Результат: 4 теста выполнены успешно, ошибок не обнаружено.

## 5. Ручное тестирование

Дополнительно проверена работа графического интерфейса:

- запуск приложения;
- добавление задач;
- выбор приоритетов;
- удаление задач;
- изменение статусов;
- обновление процента выполнения;
- сохранение и восстановление данных после повторного запуска.

Все перечисленные функции работают корректно.
