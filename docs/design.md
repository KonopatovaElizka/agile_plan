# Проектирование Agile Planner

## 1. Общая архитектура

Agile Planner разработан как локальное настольное приложение на языке Python с использованием графической библиотеки Tkinter.

Архитектура программы разделена на три основных модуля:

- `app.py` — создание графического интерфейса и обработка действий пользователя.
- `task_manager.py` — управление задачами: добавление, удаление, изменение статусов, фильтрация и расчёт прогресса.
- `storage.py` — сохранение и загрузка задач из JSON-файла.

## 2. Структура данных

Каждая задача представлена словарём Python со следующими полями:

| Поле | Назначение |
|---|---|
| id | Уникальный идентификатор задачи |
| title | Название задачи |
| priority | Приоритет задачи |
| status | Текущий статус задачи |

Пример структуры задачи:

```json
{
    "id": 1,
    "title": "Изучить Английский",
    "priority": "Высокий",
    "status": "To Do"
}
```

## 3. Графический интерфейс

Главное окно программы содержит:

- Заголовок Agile Planner.
- Поле ввода названия задачи.
- Список выбора приоритета.
- Кнопку добавления задачи.
- Таблицу со списком задач.
- Кнопку удаления выбранной задачи.
- Кнопку изменения статуса.
- Индикатор общего прогресса выполнения.

## 4. Хранение данных

Для хранения информации используется формат JSON.

Файл `data/tasks.json` содержит список задач. При запуске программы данные загружаются в память, а после изменений автоматически сохраняются в файл.

## 5. Логика работы

Основной сценарий работы программы:

1. Пользователь запускает приложение.
2. Программа загружает ранее сохранённые задачи.
3. Пользователь добавляет, удаляет задачи или изменяет их статусы.
4. Программа обновляет таблицу и процент выполнения.
5. Изменения автоматически сохраняются в JSON-файл.
