# Проектирование Agile Planner

## 1. Назначение документа

Документ описывает проектную структуру веб-приложения Agile Planner, его основные компоненты, данные и принципы взаимодействия между ними.

## 2. Общая архитектура приложения

Agile Planner представляет собой клиентское веб-приложение для личного планирования задач с использованием подхода Agile.

В проекте используются следующие технологии:
- **HTML** — формирование структуры веб-страницы.
- **CSS** — оформление интерфейса и адаптация элементов.
- **JavaScript** — обработка действий пользователя и управление задачами.
- **LocalStorage** — локальное хранение данных в браузере (планируемая реализация).

## 3. Основные компоненты интерфейса

1. **Заголовок приложения** — название и краткое описание планировщика.
2. **Форма добавления задачи** — ввод названия, описания и приоритета задачи.
3. **Список задач** — отображение созданных задач.
4. **Карточка задачи** — информация о задаче и доступные действия.
5. **Статусы задач** — To Do, In Progress и Done.
6. **Планирование спринтов** — распределение задач по этапам работы.
7. **Индикатор прогресса** — отображение выполнения запланированных задач.

## 4. Структура данных задачи

Каждая задача содержит следующие поля:

| Поле | Назначение |
|---|---|
| id | Уникальный идентификатор |
| title | Название задачи |
| description | Описание задачи |
| priority | Приоритет задачи |
| status | Текущий статус |
| sprint | Название или номер спринта |

## 5. Основные функции приложения

- Создание новой задачи.
- Редактирование существующей задачи.
- Удаление задачи.
- Изменение статуса выполнения.
- Назначение приоритета.
- Просмотр и фильтрация списка задач.
- Распределение задач по спринтам.
- Отслеживание общего прогресса.

## 6. Логика работы приложения

Пользователь вводит данные задачи через форму. JavaScript обрабатывает введённую информацию и добавляет задачу в общий список. Пользователь может изменять её параметры, удалять задачу или менять статус выполнения.

Для сохранения данных между сеансами работы планируется использовать LocalStorage браузера.
