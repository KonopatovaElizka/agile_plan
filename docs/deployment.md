# Внедрение Agile Planner

## 1. Назначение

Документ описывает порядок получения, установки и запуска настольного приложения Agile Planner.

## 2. Требования к окружению

Для работы приложения необходимы:
- компьютер под управлением Windows;
- установленный Python 3;
- поддержка библиотеки Tkinter;
- файлы проекта Agile Planner.

Дополнительные библиотеки устанавливать не требуется.

## 3. Состав приложения

Основные файлы проекта:

- `app.py` — графический интерфейс и запуск приложения;
- `task_manager.py` — управление задачами;
- `storage.py` — сохранение и загрузка данных;
- `run.bat` — запуск через командную строку;
- `run.vbs` — запуск без отображения окна командной строки;
- `data/tasks.json` — файл хранения задач.

## 4. Получение проекта

Проект можно скачать в виде ZIP-архива с GitHub или клонировать командой:

```bash
git clone https://github.com/KonopatovaElizka/agile_plan.git
```

После получения проекта необходимо распаковать архив или открыть папку репозитория.

## 5. Порядок запуска

1. Установить Python 3, если он ещё не установлен.
2. Открыть папку проекта `agile_plan`.
3. Запустить `run.vbs` для запуска без окна CMD или `run.bat` для запуска через командную строку.
4. Дождаться открытия окна Agile Planner.

Также приложение можно запустить командой:

```bash
python app.py
```

## 6. Проверка после внедрения

После запуска необходимо проверить:
- открытие главного окна;
- добавление и удаление задач;
- изменение приоритетов и статусов;
- обновление прогресса;
- сохранение данных после закрытия и повторного запуска.

## 7. Вывод

В результате подготовлена инструкция по развёртыванию настольного приложения Agile Planner. Программа работает локально, не требует веб-сервера и использует JSON для хранения пользовательских задач.
