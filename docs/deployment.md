# Внедрение Agile Planner

## 1. Назначение

Документ описывает порядок подготовки, запуска и использования веб-приложения Agile Planner.

## 2. Требования к окружению

Для работы приложения необходимы:
- персональный компьютер;
- современный веб-браузер;
- файлы проекта Agile Planner;
- локальная файловая система.

Дополнительная установка серверного программного обеспечения не требуется.

## 3. Состав приложения

Приложение состоит из следующих файлов:

- `src/index.html` — структура веб-страницы;
- `src/style.css` — оформление интерфейса;
- `src/script.js` — программная логика приложения.

## 4. Порядок запуска

1. Получить файлы проекта из репозитория GitHub или использовать локальную копию.
2. Открыть папку проекта `agile_plan`.
3. Перейти в каталог `src`.
4. Открыть файл `index.html` в веб-браузере.
5. Дождаться загрузки интерфейса приложения.

## 5. Использование приложения

После запуска пользователь может:
- создавать задачи;
- указывать описание и приоритет;
- изменять статусы задач;
- удалять задачи;
- фильтровать задачи по статусам;
- отслеживать прогресс выполнения.

Данные сохраняются в LocalStorage браузера.

## 6. Проверка после внедрения

После запуска необходимо проверить:
- корректность отображения интерфейса;
- доступность основных элементов;
- создание и удаление задач;
- изменение статусов;
- сохранение данных после обновления страницы.

## 7. Вывод

В результате подготовлена инструкция по запуску и использованию Agile Planner. Приложение может работать локально в современном веб-браузере без отдельного сервера.
