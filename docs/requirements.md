# Требования к Agile Planner

## 1. Назначение программы

Agile Planner — настольное приложение для личного планирования и управления задачами с использованием базовых принципов Agile.

Программа предназначена для одного пользователя и позволяет организовывать список задач, отслеживать их выполнение и контролировать общий прогресс.

## 2. Функциональные требования

Программа должна обеспечивать:

1. Добавление новых задач с указанием названия.
2. Назначение приоритета задачи: низкий, средний или высокий.
3. Просмотр списка созданных задач.
4. Удаление выбранных задач.
5. Изменение статуса задачи:
   - To Do — задача запланирована;
   - In Progress — задача выполняется;
   - Done — задача завершена.
6. Автоматический расчёт процента выполненных задач.
7. Сохранение задач в локальном JSON-файле.
8. Загрузку сохранённых задач при повторном запуске программы.

## 3. Нефункциональные требования

- Программа должна иметь графический интерфейс.
- Приложение должно работать локально, без подключения к серверу и интернету.
- Интерфейс должен быть понятным и простым в использовании.
- Данные должны сохраняться между запусками программы.
- Программа должна запускаться на компьютере с установленным Python 3 и поддержкой Tkinter.

## 4. Технические требования

- Язык программирования: Python 3.
- Библиотека графического интерфейса: Tkinter.
- Формат хранения данных: JSON.
- Средство тестирования: unittest.
- Операционная система для разработки: Windows.
