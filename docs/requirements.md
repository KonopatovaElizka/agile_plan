# Требования к Agile Planner

## 1. Назначение программы
Agile Planner предназначен для планирования личных задач и контроля их выполнения с использованием Agile-подхода.

## 2. Функциональные требования
- Добавление новых задач.
- Редактирование задач.
- Удаление задач.
- Установка приоритета задачи.
- Изменение статуса задачи.
- Просмотр списка задач.
- Планирование задач по спринтам.
- Отслеживание прогресса.

## 3. Нефункциональные требования
- Простой и понятный интерфейс.
- Удобство использования.
- Корректное сохранение данных.
- Работа в современном браузере.

## 4. Пользователи
Основной пользователь — владелец планировщика, который управляет своими задачами.
