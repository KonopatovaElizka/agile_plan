# Тест-кейсы Agile Planner

## 1. Проверка создания задачи

| Параметр | Описание |
|---|---|
| ID | TC-01 |
| Название | Создание новой задачи |
| Действие | Ввести название задачи и нажать «Добавить задачу» |
| Ожидаемый результат | Задача появляется в списке |

## 2. Проверка создания задачи без названия

| Параметр | Описание |
|---|---|
| ID | TC-02 |
| Название | Проверка пустого названия |
| Действие | Нажать «Добавить задачу», не вводя название |
| Ожидаемый результат | Появляется сообщение с просьбой ввести название |

## 3. Проверка изменения статуса

| Параметр | Описание |
|---|---|
| ID | TC-03 |
| Название | Изменение статуса задачи |
| Действие | Изменить статус задачи на In Progress |
| Ожидаемый результат | Новый статус отображается в карточке задачи |

## 4. Проверка удаления задачи

| Параметр | Описание |
|---|---|
| ID | TC-04 |
| Название | Удаление задачи |
| Действие | Нажать кнопку «Удалить» |
| Ожидаемый результат | Задача исчезает из списка |

## 5. Проверка фильтрации

| Параметр | Описание |
|---|---|
| ID | TC-05 |
| Название | Фильтрация по статусу |
| Действие | Выбрать фильтр In Progress |
| Ожидаемый результат | Отображаются только задачи с соответствующим статусом |

## 6. Проверка прогресса

| Параметр | Описание |
|---|---|
| ID | TC-06 |
| Название | Расчёт прогресса |
| Действие | Перевести задачу в статус Done |
| Ожидаемый результат | Счётчик выполненных задач и индикатор прогресса обновляются |

## 7. Проверка сохранения данных

| Параметр | Описание |
|---|---|
| ID | TC-07 |
| Название | Сохранение задач |
| Действие | Создать задачу и обновить страницу |
| Ожидаемый результат | Созданная задача остаётся в списке |
